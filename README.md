# 文字ならべゲーム v2

ギリシア文字（24文字）とキリル文字（33文字）を、順番にタップして並べるゲームです。

## あそびかた

- 初回は「ぜんぶ」「ひとりで」で開始します。「せってい」で「6もじ」「12もじ」「ぜんぶ」を切り替えられます。
- 短いモードでは、連続した文字の開始と終了を表示します。「つぎの文字グループ」で順に移動し、末尾の次は先頭に戻ります。設定から直接範囲も選べます。キリル文字では、末尾まで同じ文字数で練習できるよう、最後の範囲が直前の範囲と一部重なります。
- 解答途中で文字数や範囲を変更する場合は、解答を消す前に確認します。「つぎのもんだい」は現在の範囲をもう一度シャッフルします。
- 「いっしょに」は子どもから始まり、正答を置くたびに交代します。誤答や意思表示では交代しません。一人モードに戻しても並べた文字は残ります。交代モードを選び直したときや解答を消したときは子どもから再開します。
- 「みて！」「もういっかい」「てつだって」は画面下部に表示されます。タップすると約4秒間大きな文字を表示します。読み上げが有効で端末内の日本語音声を利用できる場合は、その音声で伝えます。解答、出題、手番はそのままで、クリア後も使えます。
- 効果音、読み上げ、アニメーションは個別に切り替えられます。初回はいずれも有効です。OSの「視差効果を減らす」などの設定も尊重します。
- ブラウザには言語別の設定だけを保存します。発話や録音の入力はなく、意思表示や学習履歴の送信はありません。

## ローカルでの実行とQA

Node.js 24 を使用します。

```sh
npm ci
npm test
npm run dev
```

開発用URLは [http://localhost:5173/alphabet-games/](http://localhost:5173/alphabet-games/) です。本番ビルドを確認する場合は以下を実行します。

```sh
npm run build
npx playwright install chromium webkit
npm run test:browser
```

ブラウザテストはビルド済みの3ページをローカルで配信して確認します。ギリシア・キリルの全問完走、やり直し、範囲変更時の確認、設定の復元、交代、意思表示の独立、読み上げ呼び出し、iPad相当の縦横レイアウトとタップを検証します。読み上げ呼び出しはテスト用の音声APIで確認します。実機のSafari、日本語音声の聞こえ方、親子での試用は公開前に別途確認します。

## GitHub Pagesへの移行

Viteは `dist/` に選択画面と両ゲームを出力します。公開パスは以下のとおりです。

- [ゲーム選択](https://amaeyu.github.io/alphabet-games/)
- [ギリシア文字](https://amaeyu.github.io/alphabet-games/greek-game/)
- [キリル文字](https://amaeyu.github.io/alphabet-games/cyrillic-game/)

現行の公開元は `main` のルートです。公開承認後、`main` に統合する前に Settings → Pages の公開元を **GitHub Actions** へ切り替えます。統合後に Actions → **Publish GitHub Pages** を `main` から手動実行します。これは `dist/` を同じURLに配信するための手順です。QAワークフローはテストとビルドのみを行います。 [Vite公式のGitHub Pages手順](https://vite.dev/guide/static-deploy.html#github-pages)
